# Bild-Prompts: fertig zum Kopieren

Jeder Prompt ist vollständig. Einfach den Block kopieren und in das Bild-Tool einfügen (z. B. Midjourney, Adobe Firefly, ChatGPT/DALL·E, Google Imagen).

## So gehen Sie vor

1. Prompt kopieren und Bild erzeugen. Format: Hero-Bilder Querformat 4:3, Detailbilder quadratisch 1:1.
2. Bei Midjourney zusätzlich `--ar 4:3` (Hero) bzw. `--ar 1:1` (Detail) und `--style raw` anhängen.
3. Das beste Ergebnis als PNG oder JPG speichern, **mit dem angegebenen Dateinamen**, im Ordner `public/images/neu/`.
4. Claude bitten: «Übernimm die Bilder aus public/images/neu». Claude wandelt sie in WebP um, legt sie richtig ab und prüft den Textkontrast.

**Tipps:** Für einen einheitlichen Look alle Bilder im selben Tool und mit denselben Einstellungen erzeugen. Bilder mit Text, Logos oder verzerrten Details verwerfen. Nutzungsrechte des Tools für kommerzielle Verwendung prüfen.

**Wichtig:** Das Bild «Über uns» und das Bild «Projektablauf» zeigen idealerweise die echte BEO-Werkstatt und echte Montagen. Ein echtes Foto ist dort glaubwürdiger als eine Visualisierung.
